# personal-data-denylist.txt -- patterns that must never enter this PUBLIC repo.
#
# One POSIX ERE per line. Blank lines and #-comments ignored. Matching is
# case-INSENSITIVE: the first inventory of this repo (2026-08-30) was run
# case-SENSITIVELY and found 21 files; the same grep with -i found 44, because
# `Dillon` capitalised is the dominant form. A case-sensitive denylist is a
# denylist with half its teeth.
#
# SCOPE, and it is the whole design: this gate reads ADDED LINES IN A DIFF, not
# the working tree. The repo's history and current HEAD legitimately contain
# author provenance (Dillon nodded 2026-08-30: authorship stays, history stays),
# so a whole-tree scan would fail on day one and be disabled within a week. A
# gate that must be switched off is not a gate.
#
# THEREFORE these patterns target the LEAK classes only -- machine identity and
# operator secrets -- never the AUTHOR class. "Dillon", "Dillon's", provenance
# citations and the LICENSE author line are DELIBERATELY ABSENT from this file.

# --- tailnet addresses -------------------------------------------------------
# Tailscale hands out the whole CGNAT block 100.64.0.0/10. Two earlier drafts of
# this pattern (100\.1[0-9]{2}\. and 100\.10[0-9]\.) BOTH missed the one real
# address in the repo, modules/confirm-pkg.nix relayAddr = "100.71.238.38".
# That literal is the armed bad commit in the battery for exactly this reason:
# it is the string that already defeated two instruments.
100\.(6[4-9]|[7-9][0-9]|1[01][0-9]|12[0-7])\.[0-9]{1,3}\.[0-9]{1,3}
